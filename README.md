# Prototype Satellite Designer – Thermal Monitoring System

Designed a rigid-flex, 8 layer, PCB prototype for a satellite intended to monitor permafrost
in the Arctic and Antarctic regions. The system integrated:

-a 71-Megapixel CMOS image sensor for sequential photography

-an NXP i.MX 6UL ARM Cortex-A7 System-on-Module (SOM)

-high-speed signal routing for eMMC and LVDS lines

-power integrity management
